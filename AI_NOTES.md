# AI_NOTES.md

## Использование ИИ при выполнении задания

В ходе выполнения задания ChatGPT использовался как вспомогательный инструмент для подготовки тестов и оформления документации.


### 1. Подготовка тестов

С помощью ChatGPT были подготовлены feature-тесты для проверки создания и отмены бронирований.

Тесты охватывают основные сценарии:

- успешное создание бронирования;
- проверка обязательных полей и некорректных дат;
- ограничения по продолжительности и шагу времени;
- проверка рабочего времени офиса с учётом часового пояса;
- пересечение бронирований и возможность создавать соседние интервалы;
- бронирование другой комнаты;
- невозможность отменить чужое бронирование;
- необходимость авторизации.

### 2. Подготовка документации

ChatGPT использовался для подготовки и оформления следующих файлов:

- `REVIEW.md` — описание обнаруженных проблем исходной реализации, их последствий и способов исправления;
- `README.md` — описание изменений, архитектуры решения, правил бронирования и особенностей работы с часовыми поясами;
- `AI_NOTES.md` — описание использования ИИ при выполнении задания.

При разработке в коде оставлены подробные комментарии, поясняющие логику отдельных методов, проверки и принятые технические решения. Эти комментарии также использовались как дополнительный контекст при подготовке документации. Это помогало точнее описывать фактическую реализацию и избегать расхождений между документацией и кодом.
